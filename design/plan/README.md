# Design Plans

This directory contains active delivery evidence and requirements work. It does not define evergreen architecture. Canonical intent lives in [Cognitive Architecture](../cognitive_architecture/README.md).

## Active Architecture Overhaul

[World Model Reconciliation](architecture_overhauls/world_model_knowledge_traversal/README.md) is the approved architecture program. Its assessments ground implementation scope, lifecycle connectivity, PDS framing, and requirements derivation against the canonical design.

Superseded and refused plans are removed rather than retained as live navigation. Git history preserves their provenance.

## Other Active Plans

Other folders in this directory retain authority only for their bounded delivery concern. If a plan conflicts with cognitive architecture, cognitive architecture wins and the plan must be revised or removed.
