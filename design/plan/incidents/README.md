# Delivery Incidents

This folder records failures in Meld design and delivery control that can affect the truth of an implementation acceptance claim.

An incident report preserves the observed failure, impact, causal chain, invalidated claims, retained evidence, and required prevention work. It does not replace the active program ledger or authorize remediation.
