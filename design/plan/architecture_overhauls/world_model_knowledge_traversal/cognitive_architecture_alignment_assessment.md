## Frozen Affected Set

The affected canonical set is Core, Events, Execution, Meld Language, Sensory, PDS, Runtime Lifecycle, Graph and Traversal, Belief, Planner, Epistemic Curation, Strategy, and Agent. Causation and Regime retain their ownership and require only terminology consistency.

## Entity-Level Changes

Strategy gains `StrategyPlan` as its sole complete construction product. The Plan contains desired conditions, complete Tasks, bounded Epistemic Operations, causal dependencies, frozen context, and lineage.

Agent gains durable product-level Plan progression and two explicit routes. Epistemic Operations go to Curation. Complete Tasks go to the Execution Goal Set.

Curation gains `EpistemicOperation`, authorization, result, and graph publication contracts. Graph gains owner-issued publication and occurrence-rich traversal contracts. Planner gains immutable federated cut identity.

Execution intake gains admission identity distinct from Goal and Task identity. This enables several Tasks per Goal and shared operational work across compatible admissions without exposing Strategy Plans.

PDS binds exact theory receipts, assignments, Agent genesis, participant plans, and activation generations. Runtime lifecycle binds those identities to readiness, waits, wakes, fencing, recovery, drain, and retirement.

## Removed Canonical Authority

Legacy Workflow has no canonical role. One-Task Strategy construction is superseded. Execution-side semantic replanning and world-model projection checks are refused. `DomainObjectRef` is not the epistemic substrate. Research, founding narrative, proposed synthesis, current-code routing, migration notes, and delivery state are outside the evergreen tree.

## Confidence

Confidence is high on ownership and seam alignment. Requirements-level detail remains to be derived for Plan progression persistence, Curation publication schemas, federated cut receipts, and Execution admission cardinality. Those details must preserve the canonical boundaries rather than reopen them.
