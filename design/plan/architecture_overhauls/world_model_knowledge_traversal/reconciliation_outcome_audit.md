## Required behavior

Meld must turn complete owner observations into connected, owner-qualified knowledge that an Agent can use to judge its directive. Strategy constructs the remaining epistemic and executable work against that knowledge. Agent authorizes eligible products, Curation authors epistemic results, and Execution realizes complete Tasks. Owners observe effects and admit returned evidence. Agent then maintains, satisfies, holds, or reconstructs its work. Changed knowledge must change future decisions while preserving completed history. A correctly maintained condition must not force executable work.

Simplification means one authority per responsibility, connected through existing owner products and stores. It does not mean replacing rich owner evidence with generic status, adding a second coordinator, or forcing every product into the currently demonstrated Curation-before-Task trace.

## Implementation direction

First close live Agent reconstruction through the existing Planner and Strategy contracts. This is an actual missing feedback transition and removes the driver behavior that treats the first historical authorization as the permanent route. Preserve old products and receipts under their original Plan. Persist the successor decision and completed history, resume after restart, and grant new authority only under the successor cut.

Then connect native Goal judgment and heterogeneous milestone progression to a minimal Startup product, followed by Docs observation and no-action closure. Repair lifecycle evidence ownership and instance-bound wakes as part of making those production traces truthful. Complete compatible Execution sharing and the dissimilar security trace against the same owners. Order may change when running evidence exposes a prerequisite; no outcome is dropped because of that change.

The next connected proof must start from ordinary product installation and reach returned owner evidence through the production Agent path. Native Curation installation is now connected for the shipped Docs package. Ordinary supervisor activation and explicit semantic admission epochs now replace the manual activation prerequisite in the production path. The nonce owner and its Capability must now use the existing neutral Event append and owner-publication seams. Confirmation must name exact Graph visibility and configured realization evidence before Agent acceptance and separate Goal satisfaction. Reopening and changing the admission epoch must preserve old evidence without accepting a predecessor nonce for the new epoch.

These are provisional implementation priorities, not frozen acceptance substitutes. Completion requires the actual connected product behaviors, appropriate restart and adverse-case tests, and removal of superseded runtime authority. A smaller code change that leaves another coordinator or permanently narrows the Plan grammar is not simplification.

## Implemented behavior after the initial audit

The production Agent now selects the admitted leaf of its durable Plan lineage. Changed cut identity invalidates predecessor product eligibility, invokes pure Strategy successor construction, preserves exact completed owner milestones, and atomically records successor admission with predecessor supersession. Historical authorizations no longer choose the current path by hash order. A refused successor grants no predecessor work. An unresolved admitted Execution effect remains attributable and blocks duplicate replacement work.

Curation resolves an unchanged semantic selection to its original frozen operation before Strategy construction. Agent can use a predecessor's exact completed epistemic milestone when that same semantic product remains in the successor. It does not manufacture a new Curation result. Retried Curation intake reuses the canonical Agent currentness and authority check.

Planner exposes a source-material identity for reusable executable products. Exact cut identity still fences every new authorization. This prevents unrelated Event progress from turning completed work into another executable obligation. It does not establish cross-admission sharing.

Strategy also constructs and independently verifies a no-work Plan when admitted world-state evidence already establishes the desired condition. Such a Plan has no Task, Epistemic Operation, or prospective execution evidence route. Agent separately records Goal satisfaction only after reassembling the same exact cut and checking live authority. Changed evidence creates a successor and can resume work.

Root no longer fabricates a maintained-condition breach Goal. It passes the installed condition to native Agent. Agent evaluates an exact current cut and records its own condition judgment. An already-established maintained condition creates neither a Goal nor a Plan. Missing knowledge can create a maintenance obligation without claiming an observed breach; an observed mismatch retains actual evaluation provenance. Existing Goal history remains immutable.
