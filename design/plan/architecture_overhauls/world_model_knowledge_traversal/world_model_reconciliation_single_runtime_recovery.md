## Evidence For Correction

The rejected source attempt added approximately fifteen thousand eight hundred production-path lines and removed approximately forty relative to the source checkpoint. It deleted or renamed no production file.

The implementation added `PlannerCut`, heterogeneous Strategy Plan, Agent progression, Curation, direct Task admission, and Execution return surfaces while preserving incumbent Planner projection, Strategy candidate, Agent Goal Curation, Method-planning, Goal mutation, root runtime, and legacy Workflow paths.

The failure was therefore programmatic rather than local. Source assessments and gates instructed implementors to preserve incumbent behavior beside new contracts. Logical review and Style Assurance correctly evaluated their declared boundaries but could not reject the parallel-runtime premise encoded by those boundaries.

## Preserved Architecture

The following accepted distinctions remain authoritative:

- Traversal reads admitted graph knowledge and does not perform Curation
- Curation owns bounded epistemic authorship
- Planner assembles exact immutable reasoning context
- Strategy constructs heterogeneous Plans expressing What and Why
- Agent owns Goals, Plan judgment, authorization, progression, and reconciliation
- Execution consumes complete Goal-attributed Tasks and owns How and When
- Events remains neutral durable carriage
- semantic owners produce observations and truth claims
- PDS supplies product theory, assignment, and Agent genesis inputs
- Startup proves the complete native runtime route without gating its own activation

No accepted semantic boundary requires parallel runtime implementations.

## Rejected Delivery Assumptions

The following assumptions are superseded:

- a new canonical domain implementation may be accepted before its real runtime consumer exists
- incumbent Planner, Strategy, Agent, or Execution behavior may remain unchanged beside a replacement until a later cleanup phase
- durable compatibility requires retaining an old writer or decision authority
- horizontal domain completion is valid product evidence when root runtime still follows the old path
- passing local tests and replay evidence is sufficient when no canonical cutover occurred

## Canonical Route Requirement

World Model Reconciliation now adopts the [Runtime Invariants](../../../../governance/runtime_invariants.md) without exception.

Each source delivery unit must state whether an affected responsibility keeps its current route or replaces or moves it. Replacement work must migrate its in-scope callers and delete the superseded authority in the completed change. No WMR source gate may accept equivalent incumbent and successor runtime authorities together.

Durable legacy readers may survive when stored-data evidence requires them and they cannot originate semantic work. No parallel runtime authority is approved for World Model Reconciliation.
