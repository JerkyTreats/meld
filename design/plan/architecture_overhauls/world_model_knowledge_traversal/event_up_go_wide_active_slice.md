## Observable increment

The external Codebase Semantics owner continuously inventories an isolated Gmail Operator checkout on native observation ticks. It emits bounded per-file syntax Events followed by a manifest linking the selected repository inventory and previous scan. Ordinary Meld Event reads expose source hashes, grammar identity, syntax structure, changed files, missing files and explicit grammar exclusions. Identical source produces no new scan; retained pending envelopes survive restart and retry through canonical Event append.

Selection is tracked plus nonignored untracked Git paths at the configured repository root. Python, YAML, TOML and Rust use pinned Tree-sitter grammars. Markdown, Dockerfile, ignore rules, environment examples and requirements text remain explicitly unparsed in this slice. Tree nodes retain containment, field names, order, byte spans and lexical leaves. Occurrence identity is file-revision-local, not a cross-revision symbol identity. Parse errors remain visible. No claim of reference resolution, native language adequacy or Graph admission follows from syntax transport.

## Limits and direct proof

Bound file count, file bytes, syntax node count and serialized Event size. Explicit file-level exclusions or failures remain in the manifest. Repository inventory failure must not fabricate deletions. Git paths must remain within the configured root; do not follow symlinks. Scan manifests describe sequential observations, not an atomic filesystem snapshot. Intermediate observed states are legitimate; subsequent scans reconcile material changes.

The harness checks the real 31-path baseline, parser attribution and relationships, then additions, changes, deletions, malformed source, recovery, quiet repeats and restart. It retries an actual retained envelope through public append. Runtime state remains outside the checkout. No model calls are needed. Re-run the existing native single-file sensor journey for compatibility.

Stop for a demonstrated need for a competing store, coordinator or Graph writer. Ordinary grammar exclusions or contract defects are measured domain work. Language expansion, claims curation, README replacement, release publication and settling-cost policy are outside this slice.
