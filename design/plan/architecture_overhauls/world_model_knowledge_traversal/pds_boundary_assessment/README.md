# PDS Boundary Assessment

This folder frames Persistent Domain Stewardship as Meld's productization layer over World Model Reconciliation.

The [productization reassessment](pds_productization_reassessment.md) corrects the earlier necessity framing. The [design framing after reconciliation](pds_design_framing_after_world_model_reconciliation.md) identifies the concepts from which PDS contracts can be derived.

PDS owns principal declarations, owner-issued theory packages, assignments, activations, Agent genesis, and standing responsibility. World Model Reconciliation owns live situated cognition. Product domains retain stewardship semantics and verification authority.

The canonical statement is [Persistent Domain Stewardship](../../../../cognitive_architecture/persistent_domain_stewardship.md).
