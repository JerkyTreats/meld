## Product contract

Preserve the repository observation in ground `meld-lang` propositions and native owner Graph publications. Conversion reads committed source Events, never live files. Every retained node, parent relationship, child ordinal, grammar field, kind, named/error/missing marker, byte span and lexical leaf must survive. Optional field absence is explicit. Node identity is tied to source and grammar revision, not inferred symbol identity. File status, grammar, extractor and source hash remain visible. No node count target, salience filter, guard interpretation or README claim selection is introduced.

Use the existing external Codebase Semantics observation participant and durable outbox. An explicit repository representation policy enables conversion of committed scan manifests through their exact file Event references. The owner emits its existing native publication contract and Graph admits it through Events. Each complete batch replaces the preceding repository representation at the existing owner scope. Complete describes fidelity to the observed scan; it does not mean all files parsed or code behavior understood.

## Proof, limits and review

Exploratory posture: source transport is proved, native representation at this scale is not. Start with the entire captured Gmail Operator inventory. The authoritative fidelity oracle is the retained source Event product. Native Graph must expose the same distinct information, and language queries must bind actual values and relationships without rereading source. Restart and changed-basis tests must distinguish historical observation from current representation. The previous Event-only policy and bounded single-Rust mode remain supported regression contracts.

Measure proposition count, object/relation count, serialized publication size and runtime latency. Do not hide a failure by silently dropping nodes or fields. Stop for a demonstrated need for a competing authority or a major admission redesign. Record native data fidelity separately from epistemic Fact/Belief promotion, planner usefulness and semantic density. Those higher boundaries remain open.

Logical, source-quality and gate self-review judged the same exact runtime and owner candidate in order. The qualification and its limits are recorded below. ## Measured boundary corrections

The first native publication is 32,138,185 bytes against a 16 MiB configured owner channel. An attempted append closed the child connection and left native shutdown unresolved for that isolated run. The external owner now preflights payload size and reports the exact requirement without invalidating the callback channel; the guarded refusal shuts down cleanly. The package compiler exposes the existing owner-message setting, and the candidate selects 64 MiB. No new transport or publication authority is introduced.

With that bound, the publication enters Events, but live `event tail` fails while decoding the response under its fixed three-second deadline. The correction extends the existing served Event command deadline to thirty seconds. This adds the thin Event command adapter to owned code scope; Event semantics and storage remain unchanged. Native traversal subsequently exposed its own deadline, recorded below.

The admitted repository publication also exceeds the live Graph command's five-second read/decode deadline, with a failure after roughly 20 MB of response data. The same bounded thirty-second deadline is applied to the existing Graph command adapter. The correction changes no traversal selection, publication semantics or result cardinality.

The fidelity baseline reconstructs all captured syntax, but a restart journey exposed input lag when unrelated ledger records each consumed a whole native tick. The consumer now fetches up to 64 records individually and stops after one manifest. This keeps large publications out of aggregate callback pages and preserves ordered scan conversion. Invalid authored manifest data receives a rejection Event and advances intake; transport failures retry their retained input. No alternate source store or cursor authority is introduced.

An offline source-free read initially required a current complete cut. Public evidence showed the original representation intact while Graph truthfully reported lag behind newer lifecycle and command Events. The historical-read assertion now accepts that explicit lag only when the expected revision receipt and exact native structures remain present. This preserves the user's continuous-reconciliation distinction between historical evidence and current completeness.

## Qualification and closeout

The [domain closeout](../../../../../meld-code-semantics/evidence/faithful-representation-v1/CLOSEOUT.md) and [candidate hashes](../../../../../meld-code-semantics/evidence/faithful-representation-v1/candidate.json) identify the qualified boundary. All 31 file observations reconstruct exactly from native Graph, including 12,184 syntax nodes. The baseline contains 12,216 objects, 12,215 relation occurrences and 145,523 ground propositions. A pure language query recovers all 71 expected Python function names without source access. Existing language primitives suffice for these distinctions; resolved meaning and epistemic Fact promotion remain unqualified.

The final structural run passed 53 product and cleanup assertions but retained a failed journey result because the harness treated an absent shutdown result as a dictionary. The corrected harness treats absence as pending. A separate nine-check continuation verifies the exact retained objects and relations across a quiet restart, no duplicate publication, external state and completed native shutdown. The original report remains unchanged. The same executables pass the 137-check repository Event regression and 89-check bounded Rust sensor regression. Candidate hashes and command receipts bind the composed proof to those binaries.

Native shutdown may outlast the command's initial wait. The harness now observes the exact shutdown result and confirms store release before restart; elapsed time does not imply completion. The earlier unguarded owner-channel failure remains unresolved in its own retained run. Preflight prevents that oversized-output trigger but does not qualify general owner-crash recovery. That is an open runtime reliability gap, not a closed failure hidden by the successful candidate.

Logical self-review accepted existing authority ownership, source support, rejection and ordered replay. Source-quality self-review passed strict Clippy, formatting, Python compilation and diff checks. Gate self-review accepted bounded syntax fidelity from the structural and continuation evidence. This is not an independent review or production qualification.

The complete publication is 32,146,187 bytes. The recorded debug-build query takes 22.3 seconds, with complete traversals around 9–13 seconds. Full-snapshot publication and repeated source parsing remain expensive. No efficiency, higher semantic density, symbol-resolution or README acceptance claim follows from this checkpoint. The slice is delivered; a subsequent semantic-elevation slice needs its own evidence-grounded contract.
