# Sensory Substrate

A sensory adapter binds one instrument to one owner-defined observation contract.

Every observation carries stable identity, observed subject, instrument identity, scope, source revision, observation time, payload schema, provenance, and confidence or error state.

Adapters may normalize transport data but cannot infer another domain's semantic conclusion. A workspace scanner may report that a path is absent. Docs owns whether that absence violates a README requirement. Belief owns whether the observation supports an Agent proposition.

Observation is repeatable and idempotent for an exact instrument and source revision. Changed external state produces a new observation identity and does not rewrite history.
