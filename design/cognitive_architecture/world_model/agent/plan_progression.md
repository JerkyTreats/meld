# Agent Plan Progression

Plan progression is the Agent-owned reconciliation of an authorized Strategy Plan. The name Curation is reserved for the separate epistemic authorship domain.

## Progress State

Agent records the exact Plan revision and one state for each desired condition and product. Product states distinguish blocked, eligible, authorized, published, completed, invalidated, and superseded.

## Eligibility

A product becomes eligible when its dependency conditions are admitted as satisfied under the Plan's declared perspective and frozen assumptions remain valid. Agent evaluates eligibility from durable owner results rather than process-local callbacks.

## Publication

For an Epistemic Operation, Agent publishes an authorization envelope to Curation. For a Task, Agent publishes a Goal-attributed Task admission to Execution. Both publications carry stable idempotency and lineage keys.

## Reconciliation

Agent reassesses progression after every relevant admitted fact. It never treats command acceptance as semantic completion. Curation completion, execution completion, observation, belief settlement, and Goal satisfaction remain distinct facts.

When a premise changes, Agent requests a successor Plan and preserves already completed causal history. It does not ask Execution to interpret or revise the Strategy Plan.

## Continuous reconciliation

A maintained Directive outlives any one Plan and its completion. Sensory owners continuously publish admitted observations. Agent continuously compares its relevant admitted understanding with the desired condition and asks Strategy for construction or reconstruction when material evidence changes that comparison. Strategy search is episodic and pure within this ongoing Agent loop.

A frozen planning basis can become outdated while authorized work executes. The resulting effect and its original support remain part of causal history. New material evidence makes the discrepancy actionable: Agent reassesses remaining work and the achieved state, preserves work that still contributes, and seeks a successor when correction is needed. An intermediate outdated artifact does not by itself establish failure of a maintained condition's reconciliation process.

Materiality and permissible action depend on domain theory and authority. An unrelated observation need not trigger new work. A pending conversion does not automatically prohibit every effect. Domain-specific irreversible effects may need stricter execution conditions. Continuous reconciliation requires that relevant new evidence remains observable and can drive a changed Plan without an operator repair request. Confirmation establishes the desired condition against its admitted basis; it does not terminate the standing Directive.
