# Execution Planning Pipeline

The pipeline transforms admitted complete Tasks into a durable operational Task Network.

## Normalize

Resolve stable admission, Task, Capability, artifact, authority, and resource identities. Reject malformed or unauthorized intake without interpreting producer intent.

## Match

Compare new obligations with active and completed operational work. Reuse requires exact compatibility of Capability contract, inputs, revision scope, observable effects, result shape, authority, and validity window.

## Rank

Rank ready obligations using Goal priority, deadlines, resource pressure, effect conflicts, fairness, and expected operational cost.

## Lower

Compile unmatched Task regions into Task Network nodes and attach every admission attribution to reused or new regions.

## Dispatch

Dispatch ready nodes when dependencies, resources, authority, concurrency, and effect guards permit. Persist the transition before exposing work to a Capability runner.

## Observe

Append progress, artifact, observation, completion, and failure outcomes through Events. Advance Task Network state and wake dependent work from durable records.

## Continue

Every tick repeats the same deterministic projection from Goal Set, Task Network, Capability, resource, and Event state. Ordering of runtime participants cannot be required for correctness.
